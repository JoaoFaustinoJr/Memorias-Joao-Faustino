# MEMÓRIAS — maquete editorial

Projeto visual do livro **MEMÓRIAS — João Faustino da Silva / João Faustino Major / João do Neco**.

Esta pasta é isolada do aplicativo existente no repositório. A branch `memorias-livro` foi criada para que o trabalho do livro não altere a versão atual publicada na `main`.

## Objetivo desta etapa

Definir primeiro o aspecto editorial e, somente depois de aprovado, preencher o livro integralmente.

Princípios:
- formato-base 16 × 23 cm;
- cada texto começa em nova página;
- papel marfim, azul profundo e dourado envelhecido;
- fotografias verdadeiras serão adicionadas posteriormente;
- gravuras são discretas e evocativas, nunca falsos documentos;
- notas históricas e editoriais ficam em segundo plano, ao final do capítulo;
- memória familiar e documentação externa são distinguidas;
- a voz e o texto de João Faustino Major permanecem em primeiro plano.

Abra `index.html` para ver a maquete.
